# 부동산 쇼츠 제작기 · Free Prototype V2

## 목표
서버와 유료 API 없이 브라우저 안에서 쇼츠 제작 흐름을 테스트하는 완전 무료 프로토타입입니다.

## 실행 방법
### 가장 간단한 방법
`index.html` 파일을 Chrome에서 엽니다.

### GitHub Pages
1. 이 폴더의 `index.html`을 GitHub 저장소 루트에 업로드합니다.
2. GitHub 저장소 → Settings → Pages
3. Deploy from a branch → `main` / `(root)` 선택
4. 생성된 Pages 주소로 접속합니다.

## 현재 기능
- 매물 직접 입력
- 사진 여러 장 업로드
- 무료 규칙 기반 대본 초안
- 대본 직접 수정
- 브라우저 한국어 TTS 미리듣기
- 1080×1920 Canvas 영상
- 사진 자동 줌/패닝
- 대본 기반 자동 자막
- 상호/전화번호 고정 하단 표시
- 서버 없이 브라우저 녹화
- 현재 탭 오디오를 공유하면 브라우저 TTS 음성까지 결과 영상에 포함
- 브라우저가 MP4 MediaRecorder를 지원하면 MP4, 아니면 WebM 자동 폴백

## TTS 포함 영상 만들기
1. Chrome 사용을 권장합니다.
2. `TTS + 자막 쇼츠 만들기` 클릭
3. 화면 공유창에서 **현재 탭** 선택
4. **탭 오디오 공유** 반드시 체크
5. 녹화가 끝나면 완성 영상 다운로드

## 완전 무료 구조의 한계
- 브라우저 TTS 목소리는 사용자의 OS/Chrome 환경에 따라 달라집니다.
- 모든 브라우저가 MP4 MediaRecorder를 지원하지 않으므로 WebM으로 저장될 수 있습니다.
- 규칙 기반 대본은 실제 AI만큼 자연스럽지 않습니다.
- 상용 서비스에서 동일한 음질과 동일한 MP4 결과를 보장하려면 이후 TTS/렌더 서버를 선택적으로 붙이는 것이 좋습니다.

## FFmpeg에 대해
FFmpeg 프로그램 자체는 무료 오픈소스입니다. 비용이 드는 것은 FFmpeg가 아니라 FFmpeg를 24시간 실행할 서버/CPU/스토리지/트래픽입니다. 사용자의 PC나 브라우저에서 처리하면 별도 서버 렌더 비용을 피할 수 있습니다.
