# 부동산 쇼츠 스튜디오 V3

브라우저 기반 부동산 매물 쇼츠 제작 프로토타입입니다.

## V3 핵심
- 여러 매물사진 업로드 / 추가 / 삭제 / 순서 변경
- 9:16 실시간 미리보기
- 4종 영상 템플릿
- 검정 자막 박스 제거
- POP 자막 모션
- 강조 자막 색상 선택
- 브라우저 TTS
- TTS 발화 경계 기반 자막 동기화
- BGM / 효과음 선택 및 볼륨 조절
- 외부 음원 파일 없이 Web Audio로 데모 BGM·POP·전환음을 생성
- 브라우저 영상 렌더링

## 실행
`index.html`을 Chrome에서 열거나 정적 웹 호스팅에 배포합니다.

## 참고
브라우저 TTS의 boundary 이벤트 지원 수준은 브라우저/OS 음성 엔진에 따라 다를 수 있습니다. 상용 버전에서는 타임스탬프를 제공하는 TTS API를 연결하면 프레임 단위 자막 싱크를 더 안정적으로 맞출 수 있습니다.

## V3 POP 수정

- 약 0.18초 안에 동작 완료
- 새 자막 문장으로 넘어갈 때마다 POP 모션 재시작
