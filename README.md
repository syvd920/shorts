# 부동산 쇼츠 스튜디오 V3.3

## 핵심 수정
- 사진 패닝/줌 강도를 크게 올려 미리보기에서도 눈에 띄도록 변경
- 클린: 차분한 Ken Burns
- 임팩트: 강한 줌 + 좌우 패닝
- 고급: 느리고 작은 시네마 이동
- 퀵: 가장 빠르고 강한 줌/패닝
- 자막 뒤 검정 박스/검정 그라데이션 완전 제거
- 강조형 자막은 임의의 가운데 단어가 아니라 부동산 핵심 정보 자동 강조
  - 매매/전세/월세/급매
  - 가격(억/만원)
  - ㎡/평
  - 방/욕실/룸
  - 역명
  - 남향/즉시입주/신축/올수리/역세권 등 특징
  - 입력폼의 가격/면적/방/욕실/주소/핵심특징 값
- 자막 스타일 설명을 UI에 추가
- 템플릿 설명도 실제 차이가 보이도록 구체화
