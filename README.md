# 부동산 쇼츠 스튜디오 V3.2

## V3.2 수정 내용
- 영상 템플릿 선택 영역을 편집기 맨 위로 이동
- 템플릿이 실제 자막 스타일, 자막 위치, 사진 카메라 모션, BGM/효과음 프리셋에 연결
- 클린 매물형 / 임팩트 광고형 / 고급 매물형 / 퀵 쇼츠형
- 자막을 글자 수로 자르지 않고 실제 캔버스 폭 기준으로 자동 줄바꿈
- 화면 안전영역 안에서 최대 2~3줄 표시
- 긴 문장은 폰트 크기를 자동 축소하여 화면 밖으로 나가지 않도록 처리
- 검정 자막 박스 없이 하단 그라데이션만 사용
- 새 자막 등장 시 56% → 122% → 100%로 약 0.17초 안에 빠르게 POP
- 템플릿별 사진 줌/패닝 속도 차등 적용
- 강조형 템플릿에서 선택한 강조색을 핵심 단어에 적용
- TTS 발화 경계 지원 시 실제 발화 기준 동기화, 미지원 시 시간 기반 fallback

Chrome에서 index.html을 실행하거나 정적 웹 호스팅에 배포해 테스트할 수 있습니다.
