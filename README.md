# 부동산 쇼츠 스튜디오 V3.5

## V3.5 UI 수정
- 기존의 좌측 편집 / 우측 9:16 PREVIEW 레이아웃 유지
- 최초 진입 시 좌측에는 템플릿·자막 스타일·강조색 설정만 표시
- 우측 PREVIEW는 최초 화면부터 계속 유지
- `이 템플릿으로 시작하기` 선택 후 템플릿 카드 UI는 자동으로 접힘
- 접힌 자리에는 현재 선택값을 작은 요약 바 형태로 표시
- `템플릿 다시 선택` 버튼 추가
- 다시 선택할 때 STEP 1 이후만 잠시 숨기고 템플릿 선택 UI를 다시 표시
- 기존에 입력한 매물정보·사진·대본은 삭제하지 않음
- 새 템플릿 확정 후 기존 작업을 그대로 이어서 사용 가능
- V3.4의 강한 줌/패닝 엔진과 자막 강조 로직 유지
