# 부동산 쇼츠 스튜디오 · Prototype V2.3

중개업소용 매물 쇼츠 제작 흐름을 테스트하는 브라우저 기반 프로토타입입니다.

## 실행
`index.html`을 Chrome에서 열거나 GitHub Pages 같은 정적 호스팅에 배포하면 됩니다.

## 현재 기능
- 매물정보 직접 등록
- 매물사진 여러 장 선택 및 추가
- 사진 개별 삭제 / 드래그 순서 변경
- 매물정보 기반 대본 초안
- 대본 직접 수정
- 브라우저 한국어 TTS 미리듣기
- 9:16 실시간 미리보기
- 사진 자동 줌 / 패닝
- 박스 없는 자막 + POP 등장 모션
- 자막 스타일 선택
- 상호 / 전화번호 자동 삽입
- 브라우저 Canvas 기반 영상 생성

## 영상 만들기
1. 사진과 매물정보를 입력합니다.
2. 대본 초안을 만들고 필요한 문구를 수정합니다.
3. TTS와 9:16 미리보기를 확인합니다.
4. `쇼츠 영상 만들기`를 누릅니다.
5. Chrome 공유창에서 `현재 탭`을 선택하고 `탭 오디오 공유`를 켭니다.
6. 생성이 끝나면 결과 영상을 저장합니다.
