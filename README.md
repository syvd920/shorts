# 부동산 쇼츠 스튜디오 V3.10

## 핵심 수정
이번 문제는 CSS 폭이 아니라 HTML 구조 문제였습니다.

- PREVIEW 카드가 왼쪽 제작 카드 안에 중첩되어 있던 구조 오류 수정
- 왼쪽 제작 카드와 오른쪽 PREVIEW 카드를 `.wrap`의 형제 요소로 정상 분리
- PC 화면에서 `왼쪽 제작 UI + 오른쪽 9:16 PREVIEW` 2열 고정
- 프리뷰만 오른쪽 390px 폭으로 sticky 유지
- 왼쪽 제작 UI는 남은 폭을 그대로 사용
- 템플릿 최초 선택 → 시작 후 접기 → `템플릿 다시 선택` 기능 유지
- 기존 줌/패닝, 자막 강조, TTS/BGM/효과음 로직 유지
