# 부동산 쇼츠 스튜디오 V3.4

## V3.4 변경
- 시작 화면을 `영상 템플릿 + 자막 스타일 + 강조색` 설정 전용 화면으로 변경
- `이 설정으로 시작하기`를 눌러야 STEP 1 매물등록이 열림
- 제작 시작 후 템플릿/자막 스타일/강조색 잠금
- 중간에 템플릿을 바꿔 미리보기/자막/오디오 상태가 꼬이는 문제 방지
- 선택한 제작 설정을 상단에 요약 표시
- 사진 모션 엔진을 다시 작성
  - 소스 크롭 좌표만 움직이는 방식 대신 캔버스에서 사진을 실제 확대/이동
  - 클린: 약 16% 줌 + 상하/좌우 이동
  - 임팩트: 약 28% 줌 + 강한 패닝
  - 고급: 약 9% 느린 줌 + 미세 이동
  - 퀵: 약 32% 줌 + 가장 큰 패닝
- 자막/강조색/템플릿 기능은 V3.3 기준 유지
