# 부동산 쇼츠 스튜디오 V4

## V4 핵심
- 관리자만 중개업소 ID/PW 발급
- 공개 회원가입 없음
- 사용중지 / 사용재개
- 사용기간 설정
- 등록기기 수 제한 (기본 2대)
- 기기 초기화
- 비밀번호 변경
- 동시 로그인 1개: 새 로그인 시 기존 로그인 자동 무효화
- 관리자/사용자 권한 분리
- 비밀번호는 PHP `password_hash()`로 해시 저장
- PREVIEW는 오른쪽 sticky로 고정되어 왼쪽을 스크롤해도 계속 보임
- 쇼츠 제작 기능은 V3.10 기준 유지

## 중요
이 버전은 GitHub Pages에서는 실행되지 않습니다.
계정공유 방지를 안전하게 구현하려면 서버측 PHP + MySQL이 필요합니다.
카페24 PHP/MySQL 호스팅 같은 환경에 올려 테스트하세요.

## 설치 순서
1. MySQL에서 `install.sql` 실행
2. `config.php`에 DB 접속정보 입력
3. 전체 파일을 PHP 호스팅에 업로드
4. 브라우저에서 `/setup.php` 접속
5. 최초 관리자 ID/PW 생성
6. 관리자 생성 후 서버에서 `setup.php` 삭제
7. `/index.php` 로그인
8. 관리자 화면에서 중개업소 계정 발급

## 공유 방지 방식
- 브라우저별 고유 device_id를 로컬에 생성
- 계정별 등록 가능 기기 수 제한
- 새 로그인 때 `session_version`을 증가시켜 기존 세션 자동 로그아웃
- 관리자가 기기 초기화 시 모든 등록기기를 삭제하고 기존 로그인도 해제

완벽한 계정공유 방지는 현실적으로 불가능하지만,
`동시접속 1개 + 등록기기 제한 + 관리자 강제초기화` 조합으로 일반적인 계정 공유를 상당히 억제할 수 있습니다.
